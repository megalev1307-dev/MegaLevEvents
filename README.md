# MegaLevEvents 0.1.0 — исходный проект

**Статус:** экспериментальная реализация, не собранная и не протестированная на Paper. Не устанавливайте на основной сервер без проверки на копии.

## Сборка
1. Установите Java 21 и Gradle 8.10+.
2. Откройте каталог проекта и выполните `gradle build` при доступе к интернету.
3. После успешной сборки файл будет в `build/libs/MegaLevEvents-0.1.0.jar`.
4. Установите Vault и совместимый плагин экономики для денежных функций.
5. Скопируйте JAR в `plugins/` тестового Paper-сервера и перезапустите сервер.
6. Укажите правильный мир `world:` в `plugins/MegaLevEvents/config.yml`.

## Команды
- `/event start vant`, `/event start fever`, `/event start casino`
- `/event stop vant`, `/event stop fever`, `/event stop casino`
- `/event npc` — восстановить NPC в 0/0
- `/event parkourfinish` — установить финиш на позиции администратора
- `/parkur` — телепорт к старту паркура, доступен всем

## Ограничения прототипа
- Для Ванта выбрано 24 волны лута (по 3 предмета каждые 5 секунд), потому что общее количество волн ещё не утверждено.
- Лут примерный, редактируется в config.yml, окончательные кастомные награды ещё не определены.
- Паркур-арена не строится автоматически; нужно построить и задать старт и финиш.
- Призовые шалкеры хранят содержимое в памяти: при рестарте сервера содержимое теряется. Требуется постоянное хранилище до использования на основном сервере.
- Визуал луча Вардена и Стража реализован звуком и частицами, а не настоящими двумя направленными лучами.
- Световой сигнал после смерти — частицы и молнии, не полноценный луч маяка.
- Локации ивентов используют безопасную поверхность, но не проверяют приваты WorldGuard и пользовательские регионы.
- Защита от переноса ключа через все возможные контейнеры, механики обмена и другие плагины неполная.
- На сервере с кастомным PvP/экономикой нужно отдельно проверить совместимость.
